Your Prisma schema, as a class diagram.

Open a schema.prisma and Prismagram draws every model, enum and relation as a clean UML diagram. Edit and it redraws live. Export to PNG or SVG.

Download Prismagram

Free and open source. Linux, macOS and Windows.

Readable at any sizeLarge schemas switch to a tree view: one line per model, the rest on click.
Live editingType in the editor or save in your IDE; the diagram follows.
ExportCrisp PNG at 2× or a self-contained SVG for docs and slides.
Updates itselfNew versions download in the background. Restart and you're current.

Download

Pick the installer for your computer.

Linux

Debian, Ubuntu and Kali, Fedora, or any distribution with the AppImage.

macOS

Apple silicon and Intel. macOS 11 or later.

First launch: right-click Prismagram in Applications and choose Open.

Windows

Windows 10 and 11, 64-bit.

If SmartScreen warns you, choose More info, then Run anyway.

On Linux, install the .deb with:

sudo apt install ./Prismagram_*_amd64.deb
